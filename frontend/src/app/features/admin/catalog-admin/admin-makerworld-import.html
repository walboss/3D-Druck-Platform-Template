MakerWorld-Import

Ein MakerWorld-Link je Zeile (Weg A) oder CSV-Upload mit Spalten link,category,name,tags (Weg B). „Vorschau laden" liest Titel (übersetzt), Bilder, Tags, Gewicht und Druckzeit je Link. Ohne Kategorie (weder global noch je CSV-Zeile) werden Produkte wie bisher inaktiv angelegt; mit Kategorie (Massenimport) werden sie sofort aktiv im Katalog angezeigt. Kalkulation/Preis kommt in jedem Fall danach im Produkt-Editor.
